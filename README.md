## Що зроблено

### Уніфікація
- Однаковий footer на всіх сторінках з чотирма колонками: Сторінки / Програми / Соцмережі / Правове
- Email `youth@ua-hq.com` скрізь як клікабельне `mailto:` посилання
- Favicon `logo_orig.png` на всіх сторінках

### Соціальні мережі
Скрізь лише три посилання з правильними URL:
- Instagram: `instagram.com/uniting_uayouth_worldwide/`
- LinkedIn: `linkedin.com/company/headquarters-ua/`
- Facebook: `facebook.com/profile.php?id=61586976269853`

### Мобільна адаптація
- Гамбургер-меню (≤900px) з анімацією відкриття/закриття (→ X)
- Активна сторінка підсвічена в мобільному меню
- Меню закривається при кліці на пункт

### Форма зворотного зв'язку
- AJAX-відправка через [Formsubmit](https://formsubmit.co) без перезавантаження сторінки
- Toast-повідомлення "Ваш запит прийнято" після успішної відправки
- Кнопка блокується під час відправки
- Видалено Telegram-блок

### Баги
- Виправлено перекриття навбару картою Leaflet (`isolation: isolate`)
- Виправлено подвійну вкладеність `footer-links` в `contact.html`

## Що варто покращити

### Висока пріоритетність

**1. Форма — власний email відправника**  
Зараз листи приходять від Formsubmit. Щоб відправляти від `noreply@ua-hq.com` потрібен бекенд (Cloudflare Worker + Resend API). Вимагає доступу до DNS домену `ua-hq.com`.

**2. Мобільна навігація — повноцінна**  
Зараз на мобільному пропадає весь топ-бар при скролі вниз. Варто додати автоприховування навбару при скролі вниз і появу при скролі вгору.

**3. SEO — мета-теги**  
Жодна сторінка не має `<meta name="description">`, Open Graph тегів (`og:title`, `og:image` тощо). Без цього посилання в соцмережах виглядають погано, і Google погано індексує.

**4. Картка команди — реальні дані**  
5 з 6 карток мають `[ Ім'я ]` замість справжніх імен.

### Середня пріоритетність

**5. Хостинг**  
Сайт на GitHub Pages (`youth-ua26.github.io/hq-site`) — підпапка, не корінь. Варто підключити власний домен `ua-hq.com` (безкоштовно через GitHub Pages Settings).

**6. Google Analytics / Plausible**  
Немає жодного трекінгу — невідомо скільки людей відвідує сайт і звідки.

**7. Рік в footer**  
`© 2025` — варто зробити динамічним через JS щоб автоматично оновлювався.

**8. Форма — валідація**  
Є тільки `required` на HTML-рівні. Варто додати перевірку формату email і мінімальну довжину повідомлення перед відправкою.

### Низька пріоритетність

**9. Карта на мобільному**  
Leaflet-карта висотою 520px займає весь екран на телефоні. Варто зменшити до 300px на мобільному.

**10. Темна тема**  
Сайт підтримує лише світлу тему. `prefers-color-scheme: dark` не реалізовано.

**11. 404 сторінка**  
Немає кастомної сторінки помилки. GitHub Pages показує стандартну.
